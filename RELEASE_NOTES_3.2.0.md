# Improved Shopping List Card 3.2.0

Version 3.2.0 adds Inventory mode and improves the existing Shopping-list and To-do workflows.

## Highlights

- New Inventory mode with stock-in, stock-out, registration, correction, minimum-stock handling, grouped EAN variants, filters, and short-term undo.
- Expanded EAN product database, scan queue, and optional transfer workflows between Inventory and Shopping lists.
- Improved To-do due-date actions, editing, notifications, categories, sorting, dialogs, and mobile layouts.
- Numerous reliability and usability fixes throughout the card and visual editor.

The complete configuration and workflow documentation is available in the [Wiki](https://github.com/Nisbo/ha-shopping-list-improved/wiki).
